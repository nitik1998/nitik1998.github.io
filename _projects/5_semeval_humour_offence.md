## Problem

Build NLP models to classify short text as humorous/non-humorous/offensive and predict humour intensity.

## What I Built

- Benchmarked classical ML models and deep sequence models.
- Trained transformer models including BERT, RoBERTa, and XLNet.
- Optimized BERT-large and built a BERT+MLP pipeline for rating tasks.

## Outcomes

- Achieved high classification accuracy with transformer-based models.
- Delivered competitive RMSE for humour rating.

## Technologies

- Python
- PyTorch / Transformers
- BERT, RoBERTa, XLNet
- NLP classification and regression workflows
